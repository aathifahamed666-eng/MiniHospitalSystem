# Hospital Management System

## Description
This project is a Java-based Hospital Management System developed using
different data structures.

## Data Structures Used

- Binary Search Tree (BST) - Patient Management
- Queue - Emergency Patient Management
- Stack - Treatment History
- Linked List - Patient Visit Management

## Main Features

- Add patient
- Search patient
- Delete patient
- Manage emergency patients
- Store completed treatments
- Manage patient visit records

## Technologies Used

- Java
- Object-Oriented Programming
- Data Structures and Algorithms

## Project Structure

- hospital/Patient.java
- hospital/BST.java
- hospital/EmergencyQueue.java
- hospital/TreatmentStack.java
- hospital/VisitLinkedList.java
- hospital/Main.java

## Testing

The system was tested to verify the main operations of each data structure.
